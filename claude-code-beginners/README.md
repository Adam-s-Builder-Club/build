## Your action plan

If you watched the video and want to actually do something:

1. Open `00-installation/` and follow the install guide
2. Drop `01-claude-md/global-CLAUDE.md.example` into `~/.claude/CLAUDE.md`
3. Open an empty folder, launch Claude Code, paste the prompt from `06-portfolio-website-demo/`
4. Once that's working, install one skill from `03-skills-starter/`
5. Come back next weekend and install another

Don't try to do everything in one sitting. The compounding move is consistency.
