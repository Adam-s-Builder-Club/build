## How to use a prompt

1. Open the file
2. Read the section labeled **The prompt**
3. Paste it into Claude
4. Replace bracketed parts (`[like this]`) with your specifics
5. If the prompt has a "Plan mode first" note, hit Shift+Tab+Tab before sending
